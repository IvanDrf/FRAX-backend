# FRAX-backend
Backend для web-приложения по курсу ИУ5 ПСПР

## Тема

Определение риска переломов по шкале FRAX. Услуги - факторы риска (предыдущие переломы, курение, прием глюкокортикоидов, ревматоидный артрит и др.). Заявка - расчет 10-летней вероятности основных остеопоротических переломов и перелома шейки бедра на основе выбранных факторов риска и (опционально) показателя минеральной плотности кости (МПК).

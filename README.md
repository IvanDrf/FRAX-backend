
# FRAX Backend — API для работы с факторами риска переломов

## Модели базы данных

### Таблица `users` — пользователи

| Поле | Тип | Ограничения | Описание |
| :--- | :--- | :--- | :--- |
| `id` | Integer | PK, autoincrement, index | Идентификатор |
| `username` | String(50) | NOT NULL, UNIQUE | Имя пользователя |
| `password` | String | NOT NULL | Пароль |

### Таблица `risk_factors` — факторы риска

| Поле | Тип | Ограничения | Описание |
| :--- | :--- | :--- | :--- |
| `id` | Integer | PK, autoincrement, index | Идентификатор |
| `name` | String(100) | NOT NULL | Название фактора |
| `description` | String(500) | NOT NULL | Краткое описание |
| `weight` | Float | NOT NULL, default=1 | Вес фактора (0–2) |
| `prevalence` | Integer | NULLABLE | Распространённость, % (0–100) |
| `category` | ENUM `factor_category` | NOT NULL | `Бинарный` / `Числовой` / `Категориальный` |
| `publication_status` | ENUM `publication_status` | NOT NULL | `published` / `draft` / `deleted` |
| `creator_id` | Integer | FK → `users.id`, NOT NULL | Автор фактора |
| `created_at` | TIMESTAMP(tz) | NOT NULL | Дата создания |
| `formated_at` | TIMESTAMP(tz) | NULLABLE | Дата публикации |
| `image_url` | String(255) | NOT NULL | URL изображения |
| `video_url` | String(255) | NOT NULL | URL видео |

### Таблица `likes` — лайки (м-м пользователь-фактор)

| Поле | Тип | Ограничения | Описание |
| :--- | :--- | :--- | :--- |
| `id` | Integer | PK, autoincrement, index | Идентификатор |
| `user_id` | Integer | FK → `users.id`, NOT NULL | Кто поставил |
| `risk_factor_id` | Integer | FK → `risk_factors.id`, NOT NULL | Какому фактору |

## API методы

Все эндпоинты имеют префикс `/api`. Тег `frax` — для работы с факторами, `users` — для пользователей.

### Пользователи (`/api/users`)

#### `POST /api/users/register` — регистрация

**Тело запроса (JSON):**
```json
{
  "username": "testuser1",
  "password": "secret"
}
```

**Ответы:**
| Код | Описание |
| :--- | :--- |
| `201` | Пользователь создан |
| `409` | Пользователь с таким именем уже существует |
| `422` | Ошибка валидации |

#### `POST /api/users/login` — вход

Заглушка. Пока не реализовано.

#### `POST /api/users/logout` — выход

Заглушка. Пока не реализовано.

### Факторы риска (`/api/factors`)

#### `GET /api/factors` — каталог факторов

Возвращает список **опубликованных** факторов с количеством лайков и флагом «является ли текущий пользователь создателем».

**Query-параметры:**
| Параметр | Тип | Обяз. | Описание |
| :--- | :--- | :--- | :--- |
| `risk_factor_weight` | float | Нет | Фильтр: показать факторы с весом **больше** указанного |

**Ответ `200`:**
```json
[
  {
    "risk_factor": {
      "id": 1,
      "name": "Предыдущие переломы",
      "description": "...",
      "weight": 1.5,
      "prevalence": 12,
      "category": "Бинарный",
      "publication_status": "published",
      "creator_id": 1,
      "created_at": "2026-09-20T19:28:40Z",
      "formated_at": "2026-09-20T19:30:00Z",
      "image_url": "http://localhost:9000/frax-bucket/1.jpg",
      "video_url": "http://localhost:9000/frax-bucket/1.mp4"
    },
    "likes": 3,
    "is_creator": true
  }
]
```

#### `DELETE /api/factors/{risk_factor_id}` — логическое удаление

Меняет `publication_status` на `deleted`. Удалить может **только создатель**. 

**Path-параметры:**
| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `risk_factor_id` | int | ID фактора |

**Ответы:**
| Код | Описание |
| :--- | :--- |
| `204` | Удалено (логически) |
| `422` | Ошибка валидации |


#### `GET /api/factors/reels` — лента (один фактор)

Возвращает **один** опубликованный фактор — для отображения в ленте.

**Query-параметры:**
| Параметр | Тип | Обяз. | Описание |
| :--- | :--- | :--- | :--- |
| `risk_factor_id` | int | Нет | Текущий фактор (для поиска следующего) |
| `next` | bool | Нет | Если `true` — вернуть следующий после `risk_factor_id` |

**Логика выбора:**
- Без параметров — первый опубликованный.
- С `next=true&risk_factor_id=N` — следующий после N, с «закольцовыванием» на первый.

**Ответ `200`:**
```json
{
  "risk_factor": { ... },
  "likes": 3,
  "is_liked": true
}
```

Где `is_liked` — поставил ли **текущий пользователь** лайк этому фактору

#### `GET /api/factors/draft` — получить черновик

Возвращает **единственный** черновик текущего пользователя.

**Ответы:**
| Код | Описание |
| :--- | :--- |
| `200` | `{"risk_factor": { ... }}` |
| `404` | Черновик не найден |

#### `POST /api/factors/draft` — создать/обновить черновик

Создаёт новый черновик или обновляет существующий. Загружает изображение и видео в MinIO.

**Тело запроса (`multipart/form-data`):**
| Поле | Тип | Обяз. | Ограничения |
| :--- | :--- | :--- | :--- |
| `name` | string | Да | — |
| `description` | string | Да | — |
| `weight` | int | Да | `0 ≤ weight ≤ 2` |
| `prevalence` | int | Нет | `0 ≤ prevalence ≤ 100` |
| `category` | enum | Да | `Бинарный` / `Числовой` / `Категориальный` |
| `image` | file | Да | `content_type` начинается с `image/` |
| `video` | file | Да | `content_type` начинается с `video/` |

**Ответы:**
| Код | Описание |
| :--- | :--- |
| `201` | Черновик создан/обновлён |
| `406` | Файл не является изображением/видео |
| `500` | Ошибка сохранения в MinIO |

**Что происходит:**
1. Проверка `content_type` файлов.
2. Поиск существующего черновика пользователя.
3. Создание или обновление записи в БД.
4. Загрузка файлов в MinIO (`frax-bucket`).
5. Запись `image_url` и `video_url` в БД.

#### `PUT /api/factors/draft/{risk_factor_id}` — публикация

Меняет статус черновика на `published` и проставляет `formated_at`.

**Path-параметры:**
| Параметр | Тип | Описание |
| :--- | :--- | :--- |
| `risk_factor_id` | int | ID черновика |

**Ответы:**
| Код | Описание |
| :--- | :--- |
| `200` | Фактор опубликован |
| `404` | Черновик не найден |

#### `POST /api/factors/like` — поставить/убрать лайк

**Query-параметры:**
| Параметр | Тип | Обяз. | Описание |
| :--- | :--- | :--- | :--- |
| `risk_factor_id` | int | Да | ID фактора |
| `add_like` | bool | Да | `true` — поставить, `false` — убрать |

**Ответы:**
| Код | Описание |
| :--- | :--- |
| `204` | Лайк поставлен/убран |
| `409` | Попытка поставить дважды или убрать несуществующий |
